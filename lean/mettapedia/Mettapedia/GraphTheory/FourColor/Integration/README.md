# Old `lean/fourcolor` Integration Inventory

This inventory is for the old standalone package at `lean/fourcolor/`.

Decision: do not treat the package as pure duplicate cruft. The old proof route
is not canonical, but the package contains background theory that may be useful
for the modern `Mettapedia.GraphTheory.FourColor` development.

For the current file-by-file status, including blocked gap-bearing sources and
negative examples that must not be ported as evidence, see
`OLD_FOURCOLOR_CLASSIFICATION.md`.

## Porting Discipline

For each cluster:

1. Inspect proof gaps in the exact old files being ported.
2. Port only definitions and proven lemmas, or preserve gaps honestly.
3. Prefer a shared namespace such as `Mettapedia.GraphTheory.FourColor` or
   `Mettapedia.GraphTheory` depending on generality.
4. Run the relevant Lean build after each cluster.
5. Update `../README.md` and `../ROADMAP.md` only after the code move is real.
