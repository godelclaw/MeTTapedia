# Quoted HOL Light checker sources

These files are retained inputs to
`Mettapedia.Languages.HOLLight.MeTTa.Program`. Each quotation records its
source's SHA-256 digest; the Lake input tracks changes to the source directory.
Keeping the inputs here makes quotation independent of a neighbouring checkout.

The files originate in [CeTTa](https://github.com/zariuq/CeTTa), revision
`e77c4ba35ff5e2286d0ab25c801814943bcff3e0`, under `lib/hol_light`.
