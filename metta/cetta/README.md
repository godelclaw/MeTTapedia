# Vendored CeTTa language definitions

These language definitions, and two generated grammar fixtures from CeTTa's
tests, are copied unchanged from CeTTa (https://github.com/godelclaw/CeTTa,
branch `cetta-ours`, commit `d436e11b`), keeping CeTTa's directory layout. The
GSLT parsing formalization under `lean/mettapedia/Mettapedia/GSLT/Parsing` reads
them, so MeTTapedia builds without a CeTTa checkout beside it.

Each file is a versioned (`_v1`) specification; a later revision would arrive as
a new file. CeTTa is distributed under the MIT License.
